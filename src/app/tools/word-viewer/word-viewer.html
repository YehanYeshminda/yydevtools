Unlike most tools here, this one is not purely local: a .docx has to be converted on our server before it can be displayed. The file is sent over HTTPS, converted in memory and never written to disk or kept afterwards. Worth knowing, because Word files are what contracts, invoices, CVs and reports arrive as.

Unlike most tools here, this one is not purely local: a .xlsx has to be converted on our server before it can be displayed. The file is sent over HTTPS, converted in memory and never written to disk or kept afterwards. If that matters for your workbook, the CSV Viewer reads plain .csv files entirely in this tab instead.
